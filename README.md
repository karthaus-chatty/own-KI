# 🤖 Own-KI – Lokaler Chatbot mit Web-UI & Admin-Dashboard

Ein selbst entwickelter KI-Chatbot auf Basis von:

- 🐍 Python
- 🔥 Flask
- 📊 scikit-learn (TF-IDF + Logistic Regression)
- 🌗 Dark/Light Mode
- 🔐 Login & Registrierung
- 📈 Admin-Dashboard mit Log-Analyse

---

## 🚀 Features

- Intent-Erkennung mit Machine Learning
- Konfidenz-Werte pro Antwort
- Session-Kontext (Gesprächshistorie pro Nutzer)
- Benutzer-Registrierung mit gehashten Passwörtern
- Admin-Dashboard mit:
  - Log-Statistiken
  - Intent-Auswertung
  - Unknown-Export
  - Modell-Neutraining
- Railway-ready (PORT-Umgebungsvariable)
