WordPress Security Basics

- Immer aktuelle Core-, Plugin- und Theme-Versionen einsetzen.
- Nur Plugins/Themes aus vertrauenswürdigen Quellen installieren.
- WAF/Firewall einsetzen (z.B. Wordfence – gut konfiguriert).
- Datei-Berechtigungen auf dem Server restriktiv setzen (755/644).
- Regelmäßige Backups erstellen und nicht auf dem gleichen Server speichern.
