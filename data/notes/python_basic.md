Python Grundlagen – Kurzüberblick

- Python ist eine interpretierte, dynamisch typisierte Sprache.
- Wichtige Konzepte: Variablen, Listen, Dictionaries, Funktionen, Klassen.
- Virtuelle Umgebungen helfen, Projekt-Abhängigkeiten sauber zu halten (z.B. mit venv oder pipenv).

Typische erste Schritte:
- Python-Version prüfen: python3 --version
- Virtuelle Umgebung erstellen: python3 -m venv .venv
- Aktivieren (macOS/Linux): source .venv/bin/activate
- Pakete installieren: pip install numpy pandas scikit-learn
